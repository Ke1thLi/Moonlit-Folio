# Contributing

Once the repository opens, use its Issues tab to report bugs. Include your browser and version, viewport, root or subpath configuration, and steps to reproduce. Use sample content when demonstrating a problem.

Before submitting a change, follow the [development guide](docs/Development-Guide.md), run the local checks, and explain the behavior the change addresses. For UI changes include keyboard verification and screenshots from the affected viewport. For a new asset include its source and redistribution terms.
