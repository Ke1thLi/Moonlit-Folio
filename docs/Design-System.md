# Design system

Moonlit Folio uses a compact documentation shell around a readable editorial column. The left rail and article TOC have separate controls. Mobile moves navigation into a drawer and the TOC into the reading flow.

[Tokens](../src/styles/tokens.css) define semantic surfaces, typography, spacing and indigo emphasis. The hero uses a Georgia title and a locally authored mountain illustration with text on a shaded foreground. The rest of the site uses local font stacks. Open `/design-system/` in development to inspect the component specimens.
